## 📊 RappiPlus Project: From Data to Business Decisions

### 📌 Introduction

RappiPlus is a subscription service within the Rappi ecosystem, designed to increase purchase frequency and the value generated per user. However, the business team is not yet certain whether the service is achieving its objectives.

There are several key business questions:

🛒 Are users actually purchasing more?

💰 Is the business model generating profit?

🔍 Are there missed opportunities throughout the purchasing process?

To answer these questions, the project analyses order, product catalogue, and marketing data. The analysis aims to evaluate the service's performance and identify specific opportunities for improvement.


### 🎯 Project Objectives

The project aims to answer six main questions:

🧹 Can we trust the data?

💰 Are we generating profit?

🔻 Where are we losing users?

🔄 Are users coming back?

🧪 Are product changes generating an impact?

📊 How can we effectively communicate the results?


### 🔄 Expected Outcome at Each Stage

🧹 Can we trust the data? → Clean and structured dataset

💰 Is the business profitable? → KPIs: Revenue, Cost, Profit

🔻 Where are we losing users? → Conversion Funnel

🔄 Are users coming back? → Cohort Analysis

🧪 Are the changes working? → Statistical Test

📊 How do we communicate the results? → Executive Dashboard
